# Pandas Project

A collection of beginner-friendly pandas projects built while learning data analysis with Python.

## Projects

### 1. Grocery Category Counter
- **Script:** `Grocery Category Counter/grocery_category.py`
- **Dataset:** `Grocery Category Counter/Grocery Category.csv`
- Explores grocery item categories: unique categories, item counts, category proportions, and a summary of the dataset's shape and column types.

### 2. Shop Sales Summary
- **Script:** `Shop Sales Summary/Sales_Record.py`
- **Dataset:** `Shop Sales Summary/Sales Records.csv`
- Calculates the total revenue across all sales records, along with the largest and smallest sale values.

### 3. Students Performance Analyzer
- **Script:** `Students Performance Analyzer/student_marks_analyzer.py`
- **Dataset:** `Students Performance Analyzer/student_marks_dataset.csv`
- Summarizes student marks with the average, maximum, minimum, count, and median.

## Requirements

- Python 3.x
- pandas

Install pandas with:

```bash
pip install pandas
```

## Usage

Run any script from its own folder, for example:

```bash
cd "Grocery Category Counter"
python grocery_category.py
```
